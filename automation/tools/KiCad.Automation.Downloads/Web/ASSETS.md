# Landing-page assets

PCB hero images were generated for this project from the user-selected second
landing-page concept. They are illustrative artwork, not an electrically
validated PCB or a screenshot of implemented software. Dark and light variants
share the same composition. Initial checkerboard mock is not shipped.

Source: https://github.com/rsms/inter (v4.1), accompanying Inter-LICENSE.txt.

Icons: Font Awesome Free 6.7.2, Fonticons, Inc., CC BY 4.0.
Source: https://github.com/FortAwesome/Font-Awesome/tree/6.7.2/svgs
See FontAwesome-LICENSE.txt. SVG assets are unmodified upstream artwork.
